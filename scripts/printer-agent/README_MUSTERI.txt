INTEGRA PRINTER AGENT v3.5 - MUSTERI KURULUMU

1) Windows'ta fis yazicinizi varsayilan yazici yapin.
2) Barkod/etiket yazicisinin Windows'a kurulmus ve acik oldugunu kontrol edin.
3) musteri-kurulum.bat dosyasini calistirin.
4) Size verilen kurulum kodunu girin. Ornek: INT-26-XXXX
5) Listeden barkod/etiket yazicisini secin.
6) Isterseniz test fisi basin.

Program her Windows acilisinda otomatik baslar.
Opera, Chrome ve Edge ile calisir; tarayici yazdirma penceresi acilmaz.

Etiket basiminda her fiziksel etiket Windows kuyruguna ayri bir is olarak gider.
Etiket boyutu, urun adi, fiyat ve cizgili barkod yaziciya gorsel olarak gonderilir.

Yaziciyi daha sonra degistirmek icin:
  etiket-yazicisini-ayarla.ps1 dosyasini sag tiklayip PowerShell ile calistirin.
